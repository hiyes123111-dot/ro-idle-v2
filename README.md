# 諸神放置錄 V2

以使用者提供的 V1.17 原始 ZIP 為基底製作的獨立擴充版本。V1.17 原始內容保留，V2 新內容集中於 `js/v2_content.js`，必要的轉職與畫面支援則修改在 `js/engine.js`、`js/ui.js` 與 `index.html`。

## 啟動方式

- 直接以瀏覽器開啟 `index.html`，或將整個資料夾部署到 GitHub Pages。
- 建議使用桌面版 Chrome／Edge 或 Android Chrome。
- 遊戲存檔沿用原本的瀏覽器 LocalStorage 欄位。

## V2 新增內容

- 13 個第四職業、39 個專屬技能。
- 13 把第四職業武器、裂隙防具、2 組新裝備套裝、8 張新卡片。
- 深淵裂縫下層與核心兩張新地圖，新增 6 種一般魔物與 2 隻 MVP。
- 新增 8 件「裂隙探索者的遺物」，提供 2／3／5 件套裝加成。
- 新增「神器」分頁：可收集材料製作布倫希爾德與阿斯普利卡；兩隻 V2 MVP 會掉落相關神器材料。
- 第四職業轉職支援、轉職樹顯示、三轉未使用技能點承接。
- 新職業依物理／魔法定位設定 ATK、MATK 職業係數，主動技能倍率與 SP 消耗採分段曲線；保留 V1.17 原有全域傷害公式以降低舊職業平衡風險。
- 修正奔跑者徽章與黑皮靴、改良型緊身便衣與亞麻手套的套裝效果歸屬。

## 存檔相容性

V2 以 V1.17 存檔可載入為目標。回歸測試已使用 V1.17 原始程式建立測試存檔，再由 V2 載入並保留角色職業、等級、技能、金幣與轉生路線。建議正式更新前仍先匯出遊戲內完整備份。V2 新增道具與職業資料不保證能反向載入舊版 V1.17。

## 測試

需要 Node.js 18 或更新版本，在專案根目錄執行：

```bash
node tools/v2_regression.js
```

測試內容包含套裝啟用與加成、第四職業轉職與技能、裝備與掉落資料、遺物門檻、舊存檔遷移，以及 JavaScript 語法檢查。
