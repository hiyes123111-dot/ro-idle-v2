## v2.5.478 寵物兌換券交易安全修正

- 兌換前確認持有至少 1 張兌換券；缺券不會產生寵物蛋。
- 只有扣券操作明確成功後才新增寵物蛋；扣除失敗不會發蛋。
- 加入同步兌換鎖，阻擋重入與連續呼叫重複領取。
- 發蛋操作失敗時嘗試退回兌換券；不儲存失敗交易。
- 新增 8 項兌換券測試；全專案 21 個測試檔案、1,235 項檢查通過，75 個 JS 語法檢查通過。
- 不更動第 1～8 項、野外捕捉、玩家存檔格式。
- 詳細報告：`docs/pet-audit-v2.5.478.md`。

## v2.5.477 寵物資料交易安全與離線時間修復

- 孵化、指定 UID 恢復、餵食遇到背包扣除失敗時，不會消耗部分道具或遺失已保存個體。
- 進化材料採交易式扣除；若中途扣除失敗，回補本次已扣材料並保持寵物狀態不變。

- 離線照顧校正未來時間戳，避免裝置時間回撥或異常存檔使照顧計時停滯。
- 新增 11 項安全／生命週期／窄螢幕檢查；全專案 20 個測試檔案、1,227 項檢查通過；75 個 JS 語法檢查通過。
- 不更動第 1～8 項能力、不新增野外捕捉、不改玩家存檔格式。
- 詳細報告：`docs/pet-audit-v2.5.477.md`。

## v2.5.460 Tamadora 自動戰鬥治癒

- Tamadora 親密度達非常親密（910）時，自動戰鬥可施放治癒術 Lv1。
- 戰鬥中 HP ≤ 70% 預設自動治癒；可在寵物面板關閉或調整 1%–99% HP 門檻。
- 手動與自動治癒共用 4 秒冷卻，不消耗 SP；僅在場上有存活怪物時自動觸發。
- 舊存檔不重置，新設定保存於既有寵物資料。
- 稽核：`docs/pet-audit-v2.5.460.md`；測試：`tests/test_pet460_tamadora_auto_heal.js`。
