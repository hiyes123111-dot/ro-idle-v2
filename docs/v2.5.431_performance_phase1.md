# v2.5.431 效能優化紀錄

## 本版範圍：第一階段（背包／倉庫大量道具呈現）

### 已完成
- 背包列表採分批 DOM 呈現：首次最多建立 80 個道具列，使用「載入更多」逐批增加；資料、分類統計、搜尋、排序與所有操作按鈕仍使用原本資料來源。
- 倉庫的背包側與倉庫側分別分批呈現，每側首次最多建立 100 列，兩側可獨立載入更多。
- 背包與倉庫圖片加入 `loading="lazy"`、`decoding="async"`。
- 切換分類、子分類、搜尋、排序及快速篩選時，顯示頁數回到第一批。
- 不修改玩家資料結構、存檔格式、道具數量、裝備個體、卡片、戰鬥或傷害公式。

### 效能影響與限制
- 本階段直接減少首屏建立的 DOM 節點數及圖片解碼工作，尤其適合道具種類很多的背包／倉庫。
- 目前篩選、計數及排序仍會掃描完整清單；因此這是降低畫面建構成本的第一步，尚未消除所有大型資料集的 CPU 成本。
- 下一個小階段應加入安全的清單索引／排序快取，並在道具增減、存倉取倉、販賣、開箱及讀檔時正確失效。
