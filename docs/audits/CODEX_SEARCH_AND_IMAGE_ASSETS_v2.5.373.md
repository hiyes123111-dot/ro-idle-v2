# v2.5.373 圖鑑搜尋與圖片資源稽核

## 圖鑑搜尋
- 新增 `CODEX_SEARCH_TEXT_CACHE`，依道具 ID 快取正規化搜尋字串。
- 索引內容包含目前顯示名稱、道具名稱與搜尋別名、道具類型／裝備部位、卡片名稱與搜尋別名／卡片部位、怪物名稱與搜尋別名／種族／屬性、資料 ID。
- 搜尋結果仍由原本的分類、職業篩選與頁面分頁流程處理，未改動角色存檔格式。

## 圖片
- 修復掃描到的 60 個缺失路徑。
- 佔位圖明確標示 CARD ART TBD／MONSTER ART TBD／ITEM ART TBD，不會誤稱為官方美術。
- 之後取得正式圖片時可直接覆蓋對應路徑，無需更改資料 ID。

## 已知限制
- 圖鑑搜尋索引在頁面載入後按 ID 快取；遊戲資料是啟動時載入的靜態資料。若未來新增執行期間動態道具，需在新增資料流程同步清除對應快取。
- 全專案歷史回歸測試仍含多個針對舊版資料／舊 UI 行為的斷言；本版另外提供版本專項測試，不以舊測試失敗數假裝全數通過。
