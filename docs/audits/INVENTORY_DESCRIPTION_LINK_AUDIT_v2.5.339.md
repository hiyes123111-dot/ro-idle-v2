# 背包物品說明超連結修正稽核 v2.5.339

## 問題
外部匯入物品描述含有 `<a href=...>` 等 HTML。背包與提示框直接插入 `innerHTML`，導致說明文字變成藍色底線超連結。

## 修正
- 新增 `itemDescriptionHtml()`：保留可讀文字與換行，移除所有 HTML 標籤，解碼常見 HTML entity 後再跳脫文字。
- 套用於背包個體裝備說明、一般物品／卡片說明、裝備提示、遺物提示及圖鑑物品詳情。
- 遊戲本身的按鈕、分頁與操作連結不經此處理，維持原有互動。

## 驗證
- 以 `node --check js/ui.js` 檢查語法。
- 檢查上述物品描述輸出點均呼叫 `itemDescriptionHtml()`。
- ZIP 完整性以 `ZipFile.testzip()` 驗證。
- 尚未在實際瀏覽器中逐一點擊測試所有背包／倉庫流程。
