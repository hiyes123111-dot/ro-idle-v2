# v2.5.370 圖鑑新增資料與快取稽核

## 問題
舊版 `getCodexPool()` 主要依怪物掉落、箱池、NPC 商店及鍛造配方建立道具清單。已加入 `ITEMS`、但尚未接上取得來源的新增裝備／道具不一定會進入圖鑑，造成搜尋不到。

## 修正
- 所有 `weapon`／`armor` 裝備、`ITEMS[id].addedVersion` 有值或 `ITEMS[id].codexInclude === true` 的正式新增道具，列入圖鑑清單。
- `CARDS` 仍要求同時具有 `ITEMS` 本體與卡片效果定義，避免孤兒卡片資料。
- 沒有可驗證取得來源的新增道具仍顯示資料，但明確標示來源待接入；不偽造掉落或商店。
- 圖鑑搜尋沿用既有名稱、ID、`searchTerms` 搜尋路徑。
- 新增道具顯示新增版本標記。
- 快取簽章納入實際資料鍵值與新增版本，不再只依賴資料筆數。

## 資料夾
- `js/engine.js`：圖鑑清單與快取簽章。
- `js/ui.js`：新增版本標記與取得來源提示。
- `index.html`：本機 JS／CSS cache-busting 版本。
- `docs/audits/`：本次稽核紀錄。
- `images/items/`、`images/cards/`、`images/monsters/`：沿用既有圖片分類，不將圖片散放到根目錄。

## 注意
此修正確保已登錄的新資料可被圖鑑找到；實際掉落仍須另有正式怪物掉落表、卡片掉落表、箱池、商店或合成配方。尚未接入者會顯示待補，不宣稱可取得。
