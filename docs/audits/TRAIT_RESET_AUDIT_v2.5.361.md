# v2.5.361 六大特性重置稽核

- UI：四轉六大特性配點區增加「重置特性點」按鈕；沒有已投入點數時停用。
- 確認：顯示重置項目、返還點數、免費、不影響基本素質／技能／等級／裝備。
- 引擎：`resetTraitStats()` 將六項 `traitAlloc` 設為 0，呼叫 `recomputeDerived(false)`、`saveGame()`，並記錄返還點數。
- 點數餘額仍由 `recomputeDerived()` 按目前四轉資格、BaseLv 應得點數減已投入點數計算，避免手動累加造成重複發點。
- 限制：四轉職業且 Base Lv.200 以上才能重置。
- 本次不收 Zeny，避免玩家因誤配或測試而失去重新配點機會。
