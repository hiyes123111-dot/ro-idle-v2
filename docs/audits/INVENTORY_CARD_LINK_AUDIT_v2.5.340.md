# 背包／卡片說明超連結稽核 v2.5.340

## 修正範圍
- v2.5.339 已將背包物品、裝備提示、遺物提示與圖鑑物品描述導向 `itemDescriptionHtml()`。
- 本版補齊插卡視窗 `showCardSelect()` 中已插入卡片與可插入卡片的 `c.desc`／`c.card.desc`，避免卡片描述仍以原始 HTML 直接插入 DOM。

- `itemDescriptionHtml()` 將 `<br>`、段落結尾轉成換行，移除其餘 HTML 標籤，解碼常見實體後再進行 HTML 跳脫。
- 說明中的外部網址文字保留為一般文字，不會形成可點擊超連結。
- 遊戲自身的使用、裝備、插卡、販售、存倉按鈕不在清理範圍。
