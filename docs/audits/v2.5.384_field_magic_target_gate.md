# v2.5.384 範圍魔法目標檢查稽核

## 發現
`castSkillInner()` 的 `needsMonster` 類型清單未包含 `field_aoe_magic`。因此隕石術、暴風雪、崩裂術及十字驅魔攻擊在沒有存活敵人時，可能通過目標檢查並繼續消耗施法資源。

## 修正
將 `field_aoe_magic` 加入施放前目標需求清單。現有 `needsMonster` 檢查位於 `state.sp -= spCost` 之前，因此無存活敵人時會回傳失敗，不扣 SP，也不進入技能冷卻。

## 保留
- v2.5.383 場域魔法傷害公式及立即第一跳。
- 魔導劍-LT +7 隕石術 Lv7、+11 超自然波 Lv5，各 5% 近距離普通攻擊觸發。
- SP／MSP 規則、技能倍率、技能後延遲及其他裝備能力。
