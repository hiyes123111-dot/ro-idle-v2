# v2.5.304 圖鑑與 EP21 入口稽核

## 問題根因
- 深淵海神怪物的圖鑑顯示別名曾是「深淵海王」，玩家以「深淵海神」搜尋時不會命中顯示名稱。
- EP21 副本入口先前只放在安全城鎮的「城鎮 NPC」清單；離開安全區後，地圖頁不會顯示該入口。
- EP21 地圖雖然存在，但被放在新手教學區地區清單中，不利於玩家在王國／地區選單中辨識。
- 圖鑑地圖與卡片來源快取簽章未完整涵蓋地圖怪物清單及卡片掉落表，資料擴充時有沿用舊索引的風險。

## 修正
- 深淵海神圖鑑列表、怪物詳情與卡片來源統一顯示「深淵海神」。
- 新增「EP21 試煉」獨立地區並掛入米德加爾特王國地區選單。
- 地圖分頁新增常駐「直接進入副本」按鈕；保留原城鎮 NPC 入口作為第二種進入方式。
- 加強圖鑑快取簽章，包含地圖怪物清單與 MONSTER_CARD_DROPS 的內容。
- 回歸測試放在 `tools/`，稽核文件放在 `docs/audits/`；本次沒有新增圖片資產。

## 驗證範圍
- 深淵海神怪物 ID 20811、卡片 ID 300151、0.01% 卡片掉率。
- 高經驗值地圖 `high_exp_208` 的怪物配置。
- EP21 地區與王國選單連結、地圖頁常駐入口。
- JS 語法與 ZIP 完整性。
