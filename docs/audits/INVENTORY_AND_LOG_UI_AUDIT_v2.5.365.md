# v2.5.365 UI 借鑑調整稽核

## 參考影片後採用的背包設計
- 保留本專案既有的武器／防具／卡片／遺物／道具五大分類。
- 道具分類新增快捷條件：全部、素材、消耗品、用得到的、吃了沒效果、打不開的箱子、寵物相關、箭矢。
- 快捷條件顯示符合的道具筆數，並與既有子分類及搜尋字串共同篩選。
