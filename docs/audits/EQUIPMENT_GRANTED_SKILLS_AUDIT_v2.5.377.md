# 裝備賦予技能稽核 v2.5.377

## 範圍
- 基礎：v2.5.376 完整資料包。
- 掃描 `ITEMS` 20,768 筆裝備/物品資料與 `SKILLS` 技能資料。
- 對裝備說明中明確標示「可使用／可施展／可習得」的技能，逐項比對技能資料庫與裝備技能授予欄位。
- 區分主動可使用技能 (`grantSkill` / `grantSkillWhen`) 與攻擊觸發自動詠唱 (`autoSpell`)；不把自動詠唱誤作主動技能欄位。

## 本版修正
- 新增或補齊多件裝備的直接技能授予。
- 新增條件式授予判斷：精煉門檻、職業限定/排除、套裝裝備、卡片套裝、裝備階級。
- 修正技能授予等級按技能資料庫上限裁切。
- 補齊 `變幻莫測魔術斗篷 [1]` 六項 5% 近距離普通攻擊自動詠唱：
  - 精煉 +9：地獄火焰 Lv3、鑽石星塵 Lv3。
  - 精煉 +11：雷爆術 Lv5、崩裂術 Lv5、大地墳場 Lv3、連鎖電擊 Lv3。
- +9/+11 條件只在穿戴斗篷且精煉達門檻時生效；卸下或精煉未達門檻時不會建立觸發。
- `變幻莫測魔術斗篷`的「習得自動魅影念咒 Lv10」仍是裝備能力條件，不是裝備免費授予該技能。

## 官方資料對照
- 台灣官方公告確認：變幻莫測魔術斗篷-LT 的 A 階級可使用魔法省悟 Lv1；深紅寶石結晶之墜-LT 的魔法省悟授予有職業限制，咒術士若未先習得不會因裝備而學會。
- 台灣官方公告確認：巴克斯裝甲-LT 的 D 階級可使用狙殺瞄準 Lv10。
- 非 LT 的變幻莫測魔術斗篷六項技能名稱、等級、5% 機率與精煉條件，另以 RagnaPlace 的 twRO 道具資料交叉核對；官方 LT 版與本作基礎版不是同一件裝備，未混用其數值。
