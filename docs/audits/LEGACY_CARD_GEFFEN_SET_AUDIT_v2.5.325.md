# 舊卡片與吉芬魔法大會套裝稽核 v2.5.325

## 本版修正

- 新增 `nidhogg_shadow_card`（道具 ID 4456）：鎧甲卡片，INT+5；超魔導師／大法師（咒術士）固定詠唱 -50%。目前遊戲技能為瞬間施放，固定詠唱百分比效果僅保存資料，尚不影響實際施法時間。
- 新增 `nahtzigger_card`（道具 ID 4457）：鎧甲卡片，念屬性魔法傷害 +30%。
- 兩張卡片均加入 ITEMS 與 CARDS，圖片 ID 分別為 4456、4457，來源記錄為黃金卡冊。
- 魔法屏障斗篷、魔法屏障披肩、暴力魔法斗篷的基礎搭配條件納入光明聖耀戰袍與魔法護符長袍兩種衣服 ID。
- `md_geffen_robe` 顯示名稱統一為「魔法護符長袍 [1]」。

## 稽核注意

- 本次掃描所有裝備 `condBonus.when.withCards` 引用，確認引用的卡片 ID 都能在 CARDS 找到。
- 裝備 `withItems` 仍有 12 個無 ITEMS 對應值，經檢視包含時光附魔詞條名稱（如 Hungry Bear's Power、Light Speed Move、Sharp Eagle Eye 等），並非全都是真正缺失的裝備 ID；需要另行分類處理。
- 本版不是官方歷年卡片全集的逐張完整性證明。完整覆蓋率仍需建立台灣官方各版本卡片清單作為基準，再逐筆比對名稱、ID、插槽、效果、取得來源與圖鑑。
- 魔法磁場魔戒與魔法心智魔戒的描述包含機率性持續恢復效果；本版未把它們錯誤轉成固定屬性加成，仍需獨立實作／測試其觸發流程。

## 本次補充的精煉效果

- 魔法屏障斗篷：每精煉 +3，攻擊後延遲 -2%；+9 近距離物理傷害 +5%；+11 再增加 +7%。
- 魔法屏障披肩：每精煉 +3，變動詠唱 -2%；+9 MATK +7%、治癒量 +15%；+11 全屬性魔法傷害 +7%。
- 暴力魔法斗篷：每精煉 +3，攻擊後延遲 -2%；+9 遠距離物理傷害 +5%；+11 再增加 +7%。
- 暴力魔法披肩：每精煉 +3，攻擊後延遲 -1%、變動詠唱 -1%；+9 對全體型物理／魔法傷害 +3%。
- 暴力魔法披肩 +11 的低機率 HP/SP 持續恢復是隨機觸發效果，尚未接入戰鬥觸發器；不會偽裝成固定屬性加成。
- 魔法磁場魔戒、魔法心智魔戒的週期性 HP/SP 恢復同樣尚未實作觸發器，本版不宣稱它們已完整生效。
