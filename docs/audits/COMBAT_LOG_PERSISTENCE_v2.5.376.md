# v2.5.376 戰鬥紀錄保存設計

- Storage key：`game_combat_log_history_v1:<character name>`。
- 三分類：`main`、`skill`、`ally`，每類只保存最後 1000 筆。
- 以 500ms debounce 合併短時間連續戰鬥訊息的寫入。
- 恢復時只接受字串陣列，並再次套用 1000 筆上限。
- localStorage 讀寫均有 try/catch；儲存失敗不會影響遊戲戰鬥流程。
- 切換角色名稱時會重新載入對應紀錄；新角色不會繼承舊角色的記錄。
- 清除歷史時同步寫回空陣列。
- 已知限制：同名角色會共用同一組紀錄；若同一瀏覽器內有多個不同存檔使用相同角色名稱，後續可改用存檔 UUID 作為 key。
