# v2.5.320 耶斯卡夫改造功能審核

- 城鎮新增「鐵匠珊珊」NPC。
- 10 種改造對應：凱渥寶樂格鎧甲/外袍/斗篷/披肩/戰靴/長靴/耳環/手套/戒指/項鍊 → 同部位耶斯卡夫裝備。
