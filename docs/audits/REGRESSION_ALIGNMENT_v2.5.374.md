# v2.5.374 回歸測試校正紀錄

## 為什麼修測試
v2.5.373 的部分歷史回歸測試仍用舊版程式碼片段或過時的卡片技能對應作斷言。這些斷言在現行實作已改用共用傷害鏈、時間基準、條件詞條與詳細紀錄面板後，會產生假失敗。本版只在能確認現行程式實際行為或有資料庫佐證時更新測試；不以放寬所有斷言方式製造全綠結果。

## 官方卡片資料核對
twRO RagnaPlace 的伊爾澤．艾爾．海涅卡片（300594）列出的技能只有「雷霆陣地」與「大地驅動」：
- 武器精煉每 +1：兩項技能傷害各 +1%。
- 搭配 A 階級「耶斯卡夫審判之冠」且頭冠精煉 +10 以上：頭冠每 +1，兩項技能傷害各 +12%。
因此移除測試對「灼熱岩漿」的錯誤期待，遊戲資料原本正確的兩項效果不變。

## 其他測試校正
- 艾佩斯托卡片：使用現有技能 ID `v25_windhawk_progressive_shot` 與 `wh_wild_walk`。
- 風鷹漸進射擊：清空戰場時重置層數及上次施放時間。
- 元素精靈：依 `summonNow` 記錄下次 SP 扣除時間；測試不再要求 `Date.now()` 直接出現在物件欄位。
- 太陽神頭盔：以技能 `rangeType`／武器類型的現行共用判斷驗證近遠距離加成互斥。
- 遺物減傷：接受現行技能與普通攻擊兩條承傷路徑。
- 治癒量：驗證 `healPct` 與 `healRecvPct` 進入 `healBonusPct`，並由 `healOutputMult()` 套用。
- 寶箱／卡冊：驗證單次與批次開啟均記錄來源，並以詳細歷史面板顯示。
- 頭冠階級條件：資料使用 `itemGradeMin`，不是舊測試中的 `gradeMin`。
- EP21 卡片數量：測試允許後續新增資料，不再硬鎖 18 張。

## 測試結果與限制
- JavaScript 語法檢查 210/210。
- 完整歷史回歸 149/183；尚有 34 個套件失敗。
- `v25109_after_cast_delay_regression.js` 保留未處理，因使用者已明確表示技能後延遲不用管。
- 其他失敗需逐一區分舊版斷言、未接線效果及真正的 runtime 缺陷；不可直接忽略。
- 未修改角色存檔格式、傷害倍率、掉落率或技能後延遲。
