# v2.5.363 卡片快速分類稽核

## 新增分類
- 全部：不加分類條件。
- 物理：效果文字包含「物理」、ATK 或 P.ATK。
- 魔法：效果文字包含「魔法」、MATK 或 S.MATK。
- 近距離：效果文字包含近距離，或同時近／遠距離。
- 遠距離：效果文字包含遠距離，或同時近／遠距離。

## 行為
- 分類可與既有名稱／效果／ID 關鍵字搜尋交集使用。
- 每次切換分類會更新 active 樣式、aria-pressed、顯示筆數及空結果提示。
- 分類只作用於目前部位相容且背包持有的卡片，不改變插卡核心流程。
- 使用 Node mock DOM 測試物理、魔法、近距離、遠距離及分類＋關鍵字組合。
