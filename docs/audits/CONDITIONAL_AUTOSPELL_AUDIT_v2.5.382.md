# v2.5.382 裝備觸發技能全量稽核

## 魔導劍-LT [2]（使用者提供的裝備截圖）
- 精煉 +7：一般近距離物理攻擊時，5% 機率自動施放隕石術 Lv7。
- 精煉 +11：一般近距離物理攻擊時，5% 機率自動施放超自然波 Lv5。
- 武器資料中的兩個條件觸發欄位均存在，並已對應至引擎 `conditionalAutoSpellMeta`。
- 隕石術與超自然波技能 ID 均存在，技能等級上限足以施放指定等級。
- 魔導劍為短劍，近距離觸發限制會允許短劍普通攻擊；弓類普通攻擊不會觸發這兩個 melee-only 效果。
- 觸發入口為普通攻擊命中後的 `tryAutoSpells('attack', target)`；成功後使用免費強制等級施放，不扣玩家 SP，也不受一般施放資源限制。

## 全裝備條件自動詠唱稽核
- 掃描所有裝備 `condBonus` 中以 `autoSpell_` 開頭的觸發欄位。
- 每個條目都必須有引擎 metadata，且 metadata 指向的技能 ID 必須存在。
- 另保留既有直接 `autoSpell` 條目回歸測試（93 個直接引用）。

## 本次處理
- 未發現魔導劍-LT 的 +7／+11 觸發設定缺漏，因此不改變其技能、觸發機率或傷害倍率。
- 新增全量條件自動詠唱回歸測試，避免後續新增裝備時只寫入資料描述、卻漏接觸發引擎。
- 更新版本及 26 個 HTML 快取參數至 v2.5.382。

## 驗證限制
這些測試確認資料、技能 ID、觸發註冊與攻擊事件管線相互接通；不是對瀏覽器即時戰鬥畫面的實際隨機觸發錄影或實測。遊戲內仍應以短劍近距離普通攻擊測試觸發紀錄。
