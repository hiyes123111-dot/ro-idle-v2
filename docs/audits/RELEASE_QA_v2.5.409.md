# v2.5.409 Release QA

## 本輪範圍
- 舊版卡片自動念咒消費端補齊：邪骸浪人、金屬波利、闇●盜賊、瓦爾基里蘭特克力斯。
- `tryAutoSpells()` 已支援卡片觸發被動技能：卸除武器／卸除鎧甲、脅持傷害部分、魔法效果解除。
- 邪骸浪人卡 2% 普攻觸發；盜賊套卡的 `blockSnatch` 會阻止此自動脅持。
- 金屬波利卡 5% 為本作可調整平衡預設值，官方台灣卡片頁只寫「一定機率」，未公布數字。
- 闇●盜賊單卡固定 Lv1；五件套且已習得卸除鎧甲 Lv5 時，新增 5% 自動 Lv5。
- 蘭特克力斯卡片修正錯誤技能 ID `dispell_magic` → `sa_dispell`；只清除目標目前存在的增益，不消耗黃色魔力礦石。
- RSX-0806 已清除 VIT+3 的錯誤未實裝標記；擊退免疫及不可破壞仍明確列為未實裝，不虛報完成。
