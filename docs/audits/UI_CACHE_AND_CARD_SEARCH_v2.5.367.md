# v2.5.367 UI 快取與插卡搜尋檢查

## 使用者截圖對照
- 第一張：裝備插卡頁。v2.5.366 的 `js/ui.js` 已含 `card-select-search` 搜尋欄與篩選按鈕。
- 第二張：角色頁／戰鬥訊息區。
- 第三張：背包道具頁，原本已顯示背包搜尋欄及分類按鈕。

## 根因
v2.5.366 的 `index.html` 仍將多個 JS/CSS 資源引用到 `?v=2.5.344`。即使 ZIP 內 `ui.js` 已更新，瀏覽器仍可能沿用舊 URL 的快取版本，導致插卡搜尋不出現。

## 本版修正
所有 `index.html` 中帶 `?v=` 的資源版本統一改為 `2.5.367`，強制瀏覽器重新請求最新資源。

## 未完成
戰鬥訊息區與背包道具卡片視覺尚未重新設計；本版不將其列為已完成。
