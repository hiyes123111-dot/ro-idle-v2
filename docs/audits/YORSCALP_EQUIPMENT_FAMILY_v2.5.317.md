# v2.5.317 耶斯卡夫裝備系列完整檢查

## 本版處理範圍

## 修正
- 原本鎧甲、外袍、斗篷、披肩只有 material 資料，改成可穿戴 armor 並分配 armor / garment 槽位。
- 新增缺漏的戰靴、長靴、戒指、手套、耳環、項鍊，使用資料庫 ID 與官方裝備位置。
- 接入精煉每 +2、+7、+9、+10、+12、D/C/B/A 品級能力。
- 接入物理系鎧甲＋斗篷、鎧甲＋斗篷＋戰靴組合；魔法系外袍＋披肩、外袍＋披肩＋長靴組合。
- 接入兩頂頭冠與對應身體裝備／飾品組合；戒指＋手套、耳環＋項鍊配對效果只計算一次，避免雙邊重複加成。
- 修正物理系「對全屬性對象的物理傷害」先前誤用魔法專用 allEleDmg 的問題；新增 allElePhysDmgPct 並接入普攻與物理技能共用的 weaponChainDamage。
- 攻擊後延遲減少走現有 afterAttackDelayPct 實際攻擊間隔計算。
