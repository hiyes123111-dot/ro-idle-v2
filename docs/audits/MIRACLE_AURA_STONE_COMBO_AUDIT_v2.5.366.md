# v2.5.366 奇蹟鬥氣石套裝補正稽核

## 官方修正依據
- 台灣 RO 官方 2026/10/06 維護開機公告明列：「修正『奇蹟鬥氣石、幽靈灰狼卡片』套裝未實裝問題」。
- 官方公告未在該條目重述完整數值；道具本體數值及卡片效果另以 twRO 資料庫頁面交叉核對。

## 新增資料
- 奇蹟鬥氣石 [1]，ID 491101，飾品，需求等級 130。
- 幽靈灰狼卡片，ID 300223，飾品卡，近距離物理傷害 +6%。

## 已接通效果
奇蹟鬥氣石本體：
- MDEF +10
- 暴擊傷害 +15%
- 近距離物理傷害 +10%
- 遠距離物理傷害 +10%
- 技能後延遲 -5%

搭配以下目前已有的卡片時：
- 幽靈灰狼卡片
- 天使冰蛞蝓卡片
- 冰雪兔蛞蝓卡片

追加：
- POW +5、CON +5、CRT +5
- 對全階級對象的物理傷害 +15%

## 尚待補齊／限制
- 官方列出的其他搭配卡片：灰狼、艾佩勒蜈蚣、紫樹精、最下級蠕蟲、中級蠕蟲，尚未在本版 CARDS/ITEMS 找到可確認的同名定義，因此本版不以猜測 ID 的方式連接。
- 命中物理傷害 +10% 暫未接入戰鬥公式；現有程式沒有獨立命中物理傷害乘區。本版只在道具說明揭露未套用，避免錯誤計算。
- 幽靈灰狼卡片未建立未經確認的怪物掉落率；CARDS + ITEMS 定義可讓卡冊池依既有規則收錄。

## 驗證
- `node --check js/data.js` 通過。
- `ghost_wolf_card` 同時存在 ITEMS 與 CARDS。
- `miracle_aura_stone` 裝備資料存在，條件式使用既有 `withCards` 檢查。
- 卡冊池以 CARDS + ITEMS 且名稱結尾「卡片」作為收錄條件，新增卡片符合。
