# 卡片資料庫覆蓋快照 v2.5.325

## 程式內部一致性

- ITEMS：20,701 筆。
- CARDS：646 筆定義。
- 可插卡圖鑑項目（ITEMS 有對應、卡片名稱以「卡片」結尾）：538 筆。
- ITEMS 中 ID 以 `_card` 結尾：532 筆；這個數字不是卡片總數，因為部分卡片使用其他內部 ID。
- 裝備 `condBonus.when.withCards` 引用：0 筆找不到 CARDS 定義。
- 裝備 `withItems`／`withAnyItem` 引用：12 個 ID 未在 ITEMS 找到；需按附魔名稱與真正裝備 ID 分類，不能直接當成 12 件缺裝備。

## 本版新增

- 尼德霍格幻影卡片（4456）：鎧甲卡，INT+5，固定詠唱 -50% 的職業條件保留資料。由於遊戲目前技能瞬間施放，固定詠唱效果暫時無法縮短施法時間。官方來源魔物尼德霍格幻影尚未加入本遊戲，因此目前不會偽造其怪物掉落。
- 納戶特基格卡片（4457）：鎧甲卡，念屬性魔法傷害 +30%，加入納戶特基格 0.01% 卡片掉落。
- 兩張卡片均加入 ITEMS、CARDS、卡片圖鑑及一般／盔甲卡冊可抽取池，並提供本地插圖 fallback。插圖是遊戲內自製辨識圖，不是官方原始卡面。
