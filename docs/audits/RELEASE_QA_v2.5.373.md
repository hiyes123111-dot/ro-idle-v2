- 結果：136/183 通過，47 項失敗。

- 因此本版不宣稱全專案回歸測試全數通過；需逐項釐清這 47 項後，才能宣稱完整回歸無誤。

## 主要限制
- 本輪未修改戰鬥傷害公式、職業平衡、掉落率及存檔格式，避免在缺少逐項驗證時改動既有遊戲經濟與角色資料。
- 佔位圖用來消除破圖，並非官方原始圖片。
- 圖鑑搜尋快取依靜態資料 ID 建立；若未來新增執行期間動態道具，需在新增資料流程同步失效快取。
