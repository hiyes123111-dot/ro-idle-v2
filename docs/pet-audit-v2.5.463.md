# v2.5.463 寵物培養資料保存修正

## 修正內容
- 新增 `state.petRecords`，依寵物蛋 ID 保存已培養寵物資料。
- 收回寵物時保存名稱、親密度、飢餓度、自動餵食與自動購買保留金額。
- 重新孵化同種類寵物蛋時恢復既有培養資料，不再重設親密度與名稱。
- 寵物收回期間暫停飢餓／親密度計時；重新孵化時重設照護時間起點。
- 舊版存檔遷移：若只有 `state.pet`，載入時補建 `petRecords`，不清除角色或背包資料。
- 存檔資料以原有角色存檔 JSON 保存，可隨全體備份匯出／匯入。
- 寵物圖鑑顯示已保存的培養紀錄與親密度。

## 資料模型限制
- 目前每種寵物蛋 ID 保存一份培養檔；同一種類若持有多顆蛋，重新孵化會恢復該種類最後一份培養檔。
- 捕捉與進化尚未開放；未核實的成功率、材料或進化結果不會自行假設。

## 驗證
- `tests/test_pet463_persistence.js`：14 項測試驗證收回、重新孵化、JSON 存檔往返、餵食同步、介面即時更新、設定保留、零值保留及舊存檔遷移掛接。
- 所有 HTML 資源查詢參數、`VERSION.txt` 與 Service Worker 快取統一為 `2.5.463`。
- 不清除 LocalStorage、不重置玩家存檔。
