# v2.5.321 EP21 掉落與圖鑑圖片修正紀錄

## 改造素材來源

- **耶斯卡夫的精神**：官方資料列出「覺醒耶爾圖斯主教」（22412）及「覺醒耶斯可普斯巫師」（22420）為掉落怪物；官方資料沒有公布確切機率。本作新建「耶斯卡夫神殿－2樓」狩場，遊戲內掉率暫定 1.0%。
- **魏格納商隊兌換證**、**墮落之蛇的形象**、**詛咒的象徵**：官方資料列於「遠古巨蛇（被侵蝕的坦・超困難）」寶箱獎勵。本作以 EP21 試煉王掉落代表寶箱內容，採最高難度資料列：2.0%、0.9%、2.0%。
- **耶斯卡夫的精神**另有寶箱獎勵，本作設為 2.0%。

> 官方來源頁面未公開覺醒怪物的精確掉率；本作 1.0% 是遊戲平衡設定，不是官方機率。寶箱機率依 Divine Pride 列出的最高一檔資料建模。

- 6 件耶斯卡夫裝備原圖已在封包中，但放在 `images/items/`，與裝備圖片 resolver 預期的 `images/equip/armor/` 不同；新增路徑別名。
- 16 件凱渥寶樂格／耶斯卡夫裝備在封包中找不到原圖，新增有名稱的 SVG 專屬 fallback。
- 36 張卡片缺少原始卡片點陣圖（其中包含 EP21 新卡）；新增獨立、有卡名與部位文字的 SVG fallback，並修正零 imgId 卡片的圖檔路徑。
- EP21 試煉王及兩種新增覺醒怪物新增專屬標示圖。
- 全封包圖片路徑盤點後，為缺少原始點陣圖的 578 項道具、1,125 種怪物新增具名稱的 SVG fallback；完整測試中 20,804 項道具與 2,553 種怪物的圖片路徑皆可解析。
