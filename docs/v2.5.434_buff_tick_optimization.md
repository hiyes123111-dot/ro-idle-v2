# v2.5.434 主循環 Buff 到期重算優化

## 本版修改
`gameTick()` 每 100ms 呼叫 `tickBuffs()`。舊版在每一拍都呼叫 `recomputeDerived(false)`，即使角色的 Buff 數值沒有任何變化。

本版調整為：
- Buff 持續期間仍逐拍扣除 `TICK_MS`，倒數精度不變。
- Buff 未到期時不重建衍生數值，也不替換 Buff 陣列，減少大型計算與每拍陣列配置。
- 一個或多個 Buff 到期時，才呼叫一次 `recomputeDerived(false)`。
- 「打擊強化」因 SP 不足而在倒數階段提前移除時，同樣會立即重算。
- 隊友既有的「只有 Buff 真正到期才重算」機制保持不變。

## 保留行為
- Buff 的持續時間仍按每個 100ms tick 扣除。
- Buff 數值在持續期間不變；到期的同一 tick 立即重算，無額外延遲。
- 打擊強化 SP 累積扣除仍照原本每秒扣除規則。
- Cardinal HOT、元素精靈維持費、龍騎士蓄力狀態仍每 tick／到期時照原流程執行。
- 不改攻速、傷害、命中、迴避、技能倍率、技能觸發機率、怪物 AI、掉落或存檔格式。
