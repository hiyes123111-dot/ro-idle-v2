# v2.5.474 寵物親密度門檻一致性修正

## 基底與範圍
- 基底：v2.5.473。
- 本版只修正寵物「非常親密」門檻不一致，不調整寵物數值、觸發機率、飼料、進化配方或飾品能力。
- 玩家存檔、LocalStorage、寵物個體 UID 與培養紀錄格式不變。

## 修正內容
- 寵物能力文字解析 `petTierText` 的最高階門檻由 900 改為 910，與既有 RO 親密度分級一致。
- 六組寵物進化條件由 900 改為 910。
- 進化面板與寵物圖鑑的條件文字同步顯示 910/1000。
- 900–909 仍屬「有點親密」，不會提前套用最高階靜態能力或取得進化資格。
- 910 起顯示「非常親密」，最高階能力與進化資格同步開放。

## 邊界測試
- 909：最高階能力不啟用；進化遭拒；材料不扣除。
- 910：最高階能力啟用；符合材料時進化成功。
- 全專案 17 個測試檔案、268 項檢查全部通過；寵物能力與進化專項新增 909／910 邊界檢查。
- 74 個 JavaScript 檔案語法檢查通過；HTML 本地引用缺失 0；HTML 資源版本、Service Worker cache 與 VERSION.txt 全部一致；ZIP 完整性通過。
