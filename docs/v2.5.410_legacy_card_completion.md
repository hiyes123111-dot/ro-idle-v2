# v2.5.410 — 舊卡片效果實裝補強

## 本輪完成

### 紙妖卡片（The Paper）
- 盜賊套卡必須同時具備紙妖、邪骸浪人、狂暴野貓、火忍西怒畢、舞獅五張卡。
- 限盜賊職業線啟用套裝效果。
- 藍色／黃色魔力礦石的消耗免除；其他材料、道具及鋅幣不免除。
- 原有 SP 攻擊回復效果保持，不改動每次攻擊的 SP 計算。
- 引擎在 `sageCanPay()` 與 `sagePay()` 同步判斷，避免只通過檢查卻仍實際扣除礦石。

### 狂暴木乃伊卡片（Ancient Mummy）
- 與木乃伊卡片同時裝備時，套裝效果是 `bPerfectHitAddRate,20`，即誘導／必中攻擊率增加 20%，不是額外 HIT +20。
- 已新增 `perfectHitAddRate` 命中乘區，普攻與物理技能都可觸發。
- 木乃伊卡片自身的 HIT +20 保持不變，不會被套裝重複加算。

### 古埃及王卡片（Amon Ra）
- 物理受擊時自動霸邪之陣 Lv10：基礎機率維持 3%。
- INT 99 以上提高至 6%。
- **6% 是本作平衡預設值，不是官方公布數字**；資料標記 `project-default-6-percent-at-int99`，之後若取得台灣服明確數值再替換。
