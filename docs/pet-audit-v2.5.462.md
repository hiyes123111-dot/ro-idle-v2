# v2.5.462 獨立寵物管理中心

## 本版完成
- 新增獨立主分頁「🐾 寵物」，不必進入背包的寵物分類才能管理寵物。
- 管理中心分成「我的寵物」、「寵物圖鑑」、「寵物商店」三個頁面。
- 我的寵物頁沿用既有孵化、餵食、命名、收回、自動餵食、Tamadora 自動治癒與寵物效果系統。
- 寵物圖鑑由 `petEggIds()` 與 `ITEMS` 現有資料動態產生，支援名稱、ID、道具描述搜尋。
- 圖鑑顯示持有寵物蛋數量、曾取得狀態、目前出戰狀態；持有寵物蛋且沒有出戰寵物時，可直接孵化。
- 寵物商店直接沿用既有 `petMerchantPanelHtml()` 與金幣購買流程。
- `renderPetPanel({includeShop:false})` 讓獨立管理頁不重複顯示商店；背包原本呼叫不帶參數，維持舊版顯示行為。

## 尚未開放
- 野外捕捉：捕捉道具、對應魔物與成功率仍需逐項核實，未建立正式資料前不提供猜測按鈕。
- 寵物進化：進化條件、材料與結果尚未完整核實，未完成前不顯示可執行操作。
- 全寵物飾品技能與 HP／SP 吸收效果仍按既有稽核清單逐項補完。
