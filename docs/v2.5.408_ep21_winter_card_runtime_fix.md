# v2.5.408 — EP21／冬季狩獵祭卡片效果接線修正

- EP21 卡片資訊（2025-12-16）：https://ro.gnjoy.com.tw/notice/notice_view.aspx?id=217971
- 2026 冬季狩獵祭卡片清單（2026-01-05）：https://ro.gnjoy.com.tw/notice/notice_view.aspx?id=218097

## 稽核結論
先前 v2.5.349 的官方差異稽核把七張 EP21 卡片列為缺漏，但 v2.5.407 實際資料庫已存在七張 CARDS／ITEMS 定義。本版不重複建卡，而是校正官方道具編號、圖鑑收錄欄位及 fallback 圖片，並測試現有條件效果。

## 實際修正
- 七張 EP21 卡片：核對武器等級 Lv.5 門檻、鞋子精煉 +7／+9 效果、冰角獸 SP 消耗與每精煉 +1 水屬性魔法傷害。
- 雷根貝勒亞斯／卡亞托斯：保留武器 Lv.5 條件及兩卡組合效果；亞斯卡片不包含天使型，依官方 01/13 更正。
- 雷根貝勒拓堤奧：補上缺少的基礎「命中物理傷害 +5%」，保留每精煉 +2 再 +4%，並補上海茉特卡片組合 +5%。
- 命中物理傷害：接入未暴擊普通物理攻擊及支援技能；暴擊改走 critDmgPct，不重複套用；魔法、固定傷害及官方列出的排除技能不套用。
- 雷根貝勒會長卡片：保留 CRI +5、暴擊傷害 +4%、每精煉 +2 再 +4%，搭配海茉特卡片 CRI +15、暴擊傷害 +3%。
- 11 張卡片均有辨識用 SVG fallback（不是官方原圖）。

## 命中物理傷害排除技能
依 2026/01/20 官方公告：地雷陷阱、定時爆炸陷阱、暴散陷阱、閃電衝擊、聖十字審判、捨命攻擊、獵鷹突擊、投擲金錢、一閃擊、死亡反彈、疾狼術、狼突擊、狼咬、荊棘陷阱、投擲魔幣、虎砲、龍之氣息、龍之氣息-水、魔力拳、天龍氣息、魔擊術、二道聖光、暗黑地獄、第三擊：火焰彈。岩漿噴發僅固定傷害段不支援。
