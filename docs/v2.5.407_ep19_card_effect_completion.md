# v2.5.407 — EP19 卡片效果校正與圖鑑補齊

## 來源
- 台灣 RO 官方 2026/02/24 老舊收集冊新增卡片公告：https://ro.gnjoy.com.tw/Notice/Notice_View?id=218201
- RagnaPlace twRO：冰霜花卡片 300362、廢棄的原始蠕蟲卡片 300369、洞穴燈籠魚卡片 300372、獨眼多洛蝦卡片 300375、雙眼多洛蝦卡片 300376。

## 本輪內容
- 校正冰霜花、廢棄的原始蠕蟲、洞穴燈籠魚、獨眼多洛蝦四張卡片名稱、部位、效果、精煉條件與圖鑑資料。
- 修正雙眼多洛蝦卡片：精煉 +12 的 MHP/ATK/MATK 效果與防具等級 Lv.2 的額外 RES +50 分開判斷。
- 獨眼多洛蝦卡片：精煉 +12 的四種魔法屬性傷害 +25% 不受防具等級限制；防具 Lv.2 才額外 +8%。
- 洞穴燈籠魚每精煉 +1 的念屬性魔法傷害，透過 `per1Refine` 實際進入卡片加成計算。
- 廢棄的原始蠕蟲與洞穴燈籠魚的套裝無屬性抗性 +5% 只計算一次，避免雙向條件重複加成。
- 四張卡片補上圖鑑辨識用 SVG fallback；非官方原圖，不冒充官方素材。

## 取得來源限制
官方公告確認老舊收集冊收錄名單；RagnaPlace 提供怪物掉落率 0.01% 及怪物 ID。現有遊戲內尚未確認這四隻怪物均已建立為可狩獵怪物並掛載到地圖，因此本版不把未存在的怪物硬塞進即時掉落表。卡片已納入圖鑑與老舊收集冊池；怪物實際狩獵掉落待怪物資料／地圖連動完成後再啟用。
