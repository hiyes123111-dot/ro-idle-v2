# v2.5.439 — UI 清單渲染快取優化

## 背景
v2.5.438 已有背包索引快取與分批 DOM 顯示。本版針對反覆切換背包、倉庫及圖鑑時仍會重複執行的文字清洗與舊道具名稱相容掃描，加入有上限的快取。

## 本版修改
- `js/ui.js`：`itemDescriptionHtml()` 增加 1,024 筆 LRU 快取。相同物品說明再次渲染時直接重用已跳脫的 HTML 字串，避免重複執行標籤移除、HTML entity 解碼與跳脫。
- `js/item_display_name_fix.js`：舊資料相容路徑在直接 ID 查找失敗時，可能遍歷大型 `ITEMS` 字典。新增 512 筆 LRU 快取，命中相同舊 ID 時不再重複掃描整份資料庫；真正不存在的 ID 不做負快取，避免之後動態補入資料時仍顯示舊名稱。
- 兩個快取只保存衍生字串，不修改 ITEMS、CARDS、背包、倉庫、角色或隊伍存檔。
- 所有快取皆有固定上限，避免長時間掛機因搜尋不同字串而無限制成長。
- 更新 HTML 中版本化資源參照為 2.5.439；沿用 v2.5.438 Service Worker 更新機制。

## 保留不變
- 傷害公式、攻速、技能觸發、卡片效果、掉落與怪物 AI。
- 背包物品數量、個體裝備、倉庫與存檔格式。
- 組隊、離線掛機及角色資料。

## 測試
- 新增 `tools/v2_5_439_ui_render_cache_regression.js`：4/4 通過，涵蓋輸出一致、HTML 清洗、快取上限、舊 ID fallback 避免重複掃描及直接名稱查找相容性。
- 沿用的 Service Worker 快取更新機制另以 `tools/v2_5_439_cache_update_regression.js` 驗證。發佈前另跑既有背包、存檔、組隊、戰鬥相關回歸及全 JS 語法檢查。
- 本版未做真實 Android Chrome 長時間效能量測，因此不宣稱特定百分比的加速；實際改善需以大量道具存檔及手機測試確認。
