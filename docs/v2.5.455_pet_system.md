# v2.5.455 寵物系統實裝紀錄

## 已實裝
- 既有寵物蛋孵化：消耗 1 個寵物蛋與 1 個攜帶用孵蛋器。
- 寵物收回：將目前寵物安全轉回原寵物蛋並放回背包。
- 寵物命名：每隻寵物僅能命名一次。
- 餵食：一般寵物飼料；長鼻象、金剛猿、QQ獅、肥肥犀牛使用資料庫已有的專用飼料；三種已確認 MVP 寵物可使用高級寵物飼料。
- 飢餓度與親密度：遊戲慢 tick 每分鐘下降飽足度，飽足度歸零後逐步降低親密度；親密度耗盡時自動收回寵物蛋，不永久刪除。
- 由寵物蛋描述解析可辨識的基本數值效果，套用至角色衍生數值與戰鬥數值。角色面板顯示寵物來源。
- 支援既有寵物蛋兌換券轉換成對應寵物蛋。

## 尚未實裝／待資料核對
- 野外捕捉：各馴服道具對應魔物、成功率與捕捉判定尚未全部建立，不使用猜測機率。
- 全部寵物專屬飼料、寵物飾品裝備與飾品技能。
- 寵物進化路線、材料與進化後能力。
- 需要觸發條件的特殊效果（吸收 HP/SP、治癒術、隱匿、技能觸發、特定魔物增傷等）。

- 新增執行檔 `js/v2_5_455_pet_system.js`。
- `index.html`、所有 JS 資源查詢版本與 `sw.js` runtime cache 統一為 `2.5.455`。
