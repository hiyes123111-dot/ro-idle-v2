# v2.5.444 花卉系列與23週年附魔卡片補齊

## 本輪新增
- 鬱金香卡片（300649）：飾品左；變動詠唱-5%、MSP-5%。
- 金盞花卡片（300650）：飾品左；CRI+2、近距離物理傷害+7%。
- 藍盆花卡片（300651）：飾品左；變動詠唱-5%、遠距離物理傷害+7%。
- 半邊蓮卡片（300652）：飾品右；技能後延遲-3%、變動詠唱+5%。
- 勿忘我卡片（300653）：飾品右；CRI+5、近距離物理傷害+5%。
- 銀蓮花卡片（300654）：飾品右；CRI+5、變動詠唱-3%、遠距離物理傷害+7%。
- 23週年紀念（300713）：全欄位附魔；固定詠唱-0.2秒、技能後延遲-3%、CRI+5、近／遠距離物理傷害+3%、全屬性魔法傷害+3%。

## 配對效果
- 鬱金香＋半邊蓮：變動詠唱-10%、技能後延遲-5%。
- 金盞花＋勿忘我：暴擊傷害+10%。來源另列 C.RATE+2，但目前遊戲沒有獨立 C.RATE 戰鬥欄位，因此不虛構計算方式。
- 藍盆花＋銀蓮花：暴擊傷害+10%。來源另列 C.RATE+2，同樣保留待系統支援。

## 暫緩組合
- 奇蹟花朵頭飾與花卉卡片組合：需要先核實頭飾的本機道具 ID，避免以名稱猜 ID。
- 23週年紀念與22週年紀念（雙重）、各類頭部附魔石組合：本輪僅匯入23週年紀念獨立效果；待所有對應道具 ID 可確認後再接入。

## 圖鑑／資源
- 每筆均建立 CARDS、ITEMS、官方數字 ID、codexInclude、圖片 fallback。
- 23週年紀念使用 `catalogCard: true`，納入卡片池但保留「全欄位附魔」分類，不誤標成飾品。
- 新增獨立 SVG 替代圖，不宣稱為官方卡面。
- 不新增未核實的怪物掉落來源與機率。
