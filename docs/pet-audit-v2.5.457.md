# v2.5.457 寵物資料與效果稽核

## 結果摘要

- 目前專案辨識到 **132 個可孵化寵物蛋道具 ID**。
- 排除 `unripe_apple2`：它是新手區青蘋果／馴服用途，不是孵化用寵物蛋，避免再次把它算入蛋庫。
- 重新辨識多語系寵物蛋：韓文 `큐펫`、日文 `キューペット`、英文 Pet Egg；包含 `clb_ss_egg01/02` 等非 `_egg` 結尾的蛋 ID。
- 將 `ep20_ice_egg` 納入寵物蛋候選清單；此項依現有物品描述與外部物品資料核對，仍保留原始 ID。
- 新增官方物品 ID 9145–9147：`copo_egg`、`grey_icewind_egg`、`icewind_egg`；既有 9148 `darklord_egg` 不另建重複資料。
- 132/132 寵物蛋都有可用飼料對照；部分進化寵物依資料來源使用通用寵物飼料，MVP 寵物使用高級寵物飼料。
- 寵物商人販售 **60 種**可用飼料；所有上架道具均能在 `ITEMS` 找到。6 種缺少資料庫 NPC buyPrice 的道具沿用專案補給價 1,000z，其餘沿用資料庫價格。
- 在最高親密度下，112/132 寵物有可解析的靜態數值效果；其餘 20 種屬於無靜態數值、觸發型、活動限定、指定地圖型或外文資料待核對，不把它們當成已實裝數值效果。

## 親密度與效果計算

親密度門檻依 RO pet DB 常用級距：

- 250 起：普通
- 750 起：有點親密
- 910 起：非常親密

同一隻寵物只使用目前親密度可達到的最高一階效果，不把低階與高階的同一項數值重複累加。這點已加入 runtime regression test。

已解析並接入既有戰鬥／角色加成管線的效果包括：

- STR、AGI、VIT、INT、DEX、LUK
- ATK、MATK、MHP、MSP、DEF、MDEF、HIT、FLEE、CRI、完全迴避
- POW、SPL、P.ATK、S.MATK、C.RATE、RES、MRES
- ATK／MATK 百分比、近／遠距離物理傷害、暴擊傷害
- 種族物理／魔法增傷、種族承傷減免、屬性物理／魔法增傷、屬性抗性
- HP／SP 自然恢復、治癒量、經驗值加成、誘導攻擊必中機率
- 異常狀態抗性；可明確判定的睡眠免疫已接入抗性判定

效果透過 `effectiveGearBonuses()` 合併到既有公式，不建立另一套平行傷害計算。完全迴避直接補入角色衍生數值；誘導攻擊使用既有 `perfectHitAddRate` 命中判定。

## 已有明確機率並接入的特殊效果

- 皮里恩寵物：誘導攻擊機率依親密度為 5%／10%／15%。
- 小鴨玩具寵物：誘導攻擊機率依親密度為 5%／10%。
- 可由道具說明確認的睡眠免疫接入異常狀態抗性。

## 尚未假裝完成的特殊效果

下列效果的來源描述未提供可核實機率，或本作缺少相應的戰鬥模型，因此保留在寵物面板稽核提示，不自行猜測觸發率：

- 攻擊吸收 HP／SP、受擊後持續恢復 HP／SP。
- 受擊自動施展治癒術、霸邪之陣；攻擊自動施展治癒術／火箭術。
- 隱匿等寵物主動技能。
- EP17 小不點管理員 α／β 的指定地圖增傷，尚缺地圖與魔物標籤的對接。
- Blue Unicorn／Dark Lord 的移動速度效果；本作目前沒有移動速度模型。
- 活動限定經驗／移動效果；本作目前沒有活動期間開關。
- 變動詠唱與技能後延遲：資料可解析，但本作沒有施法時間／技能後延遲計時模型，因此不會併入實際戰鬥加成。
- Tamadora 自動治癒術等外文觸發描述：已列入待接入提示，未偽稱已施放。
