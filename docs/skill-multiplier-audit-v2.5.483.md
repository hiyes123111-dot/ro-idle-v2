# v2.5.483 技能倍率與新增技能整合稽核

## 發現並修正的問題

### 狂野疾行（wh_wild_walk）
- v2.5.482 技能資料陣列已是每段 700%、1,050%、1,400%、1,750%、2,100%，固定 3 段攻擊。
- 但 `engine.js` 仍殘留舊官方公式，會把每段倍率再乘 BaseLv/100，並加入 CON、自然親和與鋼製喙加成。
- 共用 `mult` 早已包含 `skillDmgPct`，舊公式又乘一次技能增傷，造成重複計算。
- v2.5.483 移除該舊分支，現在直接使用共用 `mult` 作為每段倍率。技能增傷只計算一次；FLEE +100～300、持續 6～18 秒、SP 63～75、3 段攻擊保留。

### 橫揮斬（v25_dragon_knight_6）
- 載入 `v2_5_content.js` 與 `v2_6_skill_migration.js` 後，runtime 倍率為 Lv1 700%、Lv10 2,100%，中間等級線性成長。
- `type=damage_aoe`，範圍物理攻擊；保留雙手劍限制、近距離判定及 EP21 特力斯卡片使用的既有技能 ID。
- 沒有發現後續 migration 將倍率覆蓋回舊值。
