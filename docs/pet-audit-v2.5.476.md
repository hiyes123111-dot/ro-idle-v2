# v2.5.476 寵物圖鑑技能摘要修正

## 基底與範圍
- 基底：v2.5.475。
- 僅修正銀月魔女（`loli_ruri_egg`）寵物效果摘要，不更動戰鬥觸發邏輯、機率、技能等級、能力數值或存檔格式。

## 發現的問題
- 親密度低於 750 時，通用解析仍顯示「技能觸發／使用能力（需逐項接入技能流程）」，但實際能力只是尚未解鎖，造成圖鑑錯誤標示為待實裝。
- 親密度達 750 後，圖鑑可能同時顯示「近距離物理攻擊」及較寬泛的「受到物理傷害」兩筆治癒術摘要，且技能條件不夠精確。

## 修正內容
- 0–749：移除通用待接入標記，只顯示親密度達 750 後解鎖的條件。
- 750–909：只顯示近距離普通物理攻擊命中時 1% 自動施展治癒術 Lv1（已實裝）。
- 910 以上：只顯示近距離普通物理攻擊命中時 1% 自動施展治癒術 Lv2（已實裝）。
- 圖鑑摘要與既有 `tryPetOnPhysicalDamageTaken` 實際限制一致；遠距離普攻及物理技能不會被描述成可觸發。
- 不修改寵物數值、官方機率、其他寵物效果或玩家資料。
