## 本輪發現並修正
1. **齊爾-D-01卡片**：v2.5.416原始專案效果為 `skillCdFlat: -3`。v2.5.417曾覆寫為 `skillAfterDelayPct: 30`。本版恢復原始專案效果。實際測試基礎冷卻10秒 → 7秒。
2. **資深紅椒卡片**：原資料 `hpRate: 3` 未被最大HP計算讀取；新增正規化別名 `hpRate` → `hpPct`。
3. **天鷹座卡片**：原資料 `allResistPct: -30` 未進承傷計算；新增正規化別名 `allResistPct` → `eleDmgReduce_all`，負值保留為降低抗性／增加承傷。
