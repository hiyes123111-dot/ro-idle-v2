# v2.5.443 圖鑑官方 ID 搜尋修正

## 問題
既有 `getCodexSearchText()` 索引 row/item/card/monster 名稱、別名、部位、種族、屬性及內部 ID，但未納入 `imgId`／`itemId`／`cardId`。玩家輸入來源資料庫的官方數字 ID 時，可能找不到已收錄的資料。

## 修正
- 新增 row、ITEMS、CARDS、MONSTERS 的 `imgId` 與相應 `itemId`／`cardId` 欄位至搜尋文字。
- 保留原有名稱、別名、分類及內部 ID。
- 不變更卡片效果、觸發機率、掉落來源或玩家存檔。

## 驗證
- 新增 `tools/v2_5_443_codex_official_id_search_regression.js`，驗證卡片與一般道具官方數字 ID 可被搜尋。
- 發行版本、HTML 資源引用及 Service Worker 快取統一為 2.5.443。
