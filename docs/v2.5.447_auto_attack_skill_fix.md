# v2.5.447 自動攻擊技能施放修正

## 修正範圍
- 基底：使用者提供的 v2.5.446 完整 ZIP。
- 修正自動戰鬥第一招通過外層條件、但 `castSkill()` 實際回傳失敗時仍直接結束函式，導致第二招無法接手的問題。
- 第一招成功施放才結束本輪；失敗則繼續檢查第二招。
- 舊存檔若缺少第一招 `spThreshold`，自動補預設 30%；第二招 SP 門檻與怪物數門檻也採安全預設。
- 怪物數量只計算仍存活的怪物。第二招維持使用者設定的怪物數量門檻。
- 不修改卡片／賢者自動念咒、主動技能冷卻、傷害公式、玩家資料或存檔內容。自動念咒仍走 `free:true` 獨立路徑，不寫入玩家主動技能冷卻。

## 回歸測試
- 第一招失敗後第二招接手：通過。
- 第一招成功後不重複施放第二招：通過。
- 舊存檔缺少第一招 SP 門檻：通過。
- 第二招怪物數量門檻：通過。
- 兩招都失敗時正常返回、不阻塞主循環：通過。
- 專項測試：5/5 通過。
