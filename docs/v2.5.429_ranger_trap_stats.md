# v2.5.429 — 風鷹陷阱觸發統計

## 範圍
只統計目前仍以普通攻擊觸發的四轉陷阱技能，不把已改回主動施放的遊俠／風鷹技能誤標為被動觸發。

## 記錄欄位
- `eligible`：角色已學習該陷阱，且一次普通攻擊進入該技能檢查的次數。
- `rolls`：實際進行機率判定的次數。
- `procs`：成功觸發次數。
- `cooldownSkips`：因內部冷卻尚未結束而略過的次數，不算失敗擲骰。
- `fixedTriggers`：沒有機率欄位、冷卻結束即固定觸發的次數，不列入實測率分母。

## UI
自動戰鬥頁新增「風鷹陷阱觸發統計」，即時更新；顯示符合攻擊、觸發檢查、觸發次數、實測率與冷卻略過。提供重置按鈕。

## 存檔相容
新角色初始化 `rangerProcStats`；舊存檔讀取時補空物件，不刪除玩家資料。統計透過既有存檔節流機制保存。
