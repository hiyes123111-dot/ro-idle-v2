# v2.5.467 寵物圖鑑／進化資料整合

## 本版範圍
- 以 v2.5.466 為基底，只完成寵物圖鑑與既有進化配方整合。
- 野外自動捕捉維持暫緩，不新增捕捉率、捕捉按鈕或捕捉流程。
- 不新增第二套寵物／進化資料表；直接使用 ITEMS、PET_EVOLUTION_RECIPES_466 與既有 petRecords。

## 圖鑑整合
- 每筆具有進化關係的寵物蛋，在圖鑑中顯示「進化關聯」。
- 原型寵物顯示可進化結果；進化後寵物顯示其進化來源。
- 顯示目前配方的親密度條件（900/1000）及完整材料名稱、數量。
- 搜尋索引涵蓋寵物本身名稱、進化前後型態、寵物蛋 ID、材料名稱及材料 ID。
- 搜尋進化結果名稱可同時找到進化前與進化後型態；搜尋材料也能找到對應原型寵物。
- 已進化且仍出戰或已收回保存的個體，會在圖鑑中標記為已取得／保存。
- 若同一種類同時有出戰個體與已收回個體，狀態會同時顯示，不再只顯示出戰狀態而隱藏保存數量。

## 資料完整性
- 配方仍由 v2.5.466 單一來源提供，圖鑑不複製或自行修改配方。
- 本版不修改材料數量、親密度門檻、成功率或寵物能力。
- 不更動玩家 LocalStorage、不重置角色、不清除玩家存檔。
- 新增程式放在 `js/`，測試放在 `tests/`，版本稽核文件放在 `docs/`。
