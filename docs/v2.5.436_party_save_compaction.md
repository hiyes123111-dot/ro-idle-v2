# v2.5.436 組隊存檔縮減與重新整理問題

## 使用者回報
暗影十字擔任隊長，組隊前往練功地圖後重新整理，重新進入時回到安全區且隊伍消失。

## 存檔檢查
上傳的暗影十字 slot4 JSON 約 786 KB，其中 `codex` 約 501 KB、`autoSellConfig` 約 209 KB；自動販賣清單含 12,233 個 ID。隊友快照會複製角色大部分欄位，但過去未排除 `autoSellConfig`，使每名隊友都重複攜帶玩家專屬的自動販賣清單。

`saveGame()` 原本在 localStorage 寫入失敗時靜默忽略例外。若瀏覽器儲存配額耗盡，最新地圖與 `state.allies` 便不會寫入；重新整理自然會讀回上一份（可能仍在安全區、尚未組隊）的存檔。這與使用者描述的症狀吻合，是目前最有根據的根因候選，但仍需在使用者裝置上驗證是否實際觸發 QuotaExceededError。

## 修正
- `ALLY_SNAPSHOT_DROP` 加入 `autoSellConfig`、`offlineLog`、`lootNotices`。
- `loadGame()` 遷移舊隊友快照時，刪除上述玩家專屬資料，讓舊隊伍也能縮小。
- `saveGame()` 第一次寫入失敗時記錄 console error 並顯示提示，不再讓使用者誤以為已儲存成功。
- 不更動玩家本人的 `autoSellConfig`、圖鑑、地圖、隊伍成員或死亡復活機制。

## 驗證重點
- 隊友快照不含玩家自動販賣清單。
- 建立快照不修改原角色的自動販賣設定。
- 重新讀取舊快照會清除重複的玩家專屬資料。
- `saveGame()` 寫入失敗會提示；成功儲存會清除錯誤狀態。
