# v2.5.429 核心系統優化紀錄

## 風鷹陷阱觸發統計
- 新增每技能 `eligible`、`rolls`、`procs`、`cooldownSkips`、`fixedTriggers`。
- 機率失敗才計入 rolls；冷卻略過獨立統計；固定觸發不列入機率實測率分母。
- 自動戰鬥頁即時顯示統計並可重置。
- 新角色初始化統計；舊存檔讀取時補欄位；統計使用既有節流存檔，不清除玩家資料。

## 四轉被動稽核
- 13 個四轉職業、212 項技能、73 項被動技能資料完成掃描。
- 兩項樞機主教特殊被動（靈魂忠誠、鈍器＆書籍精熟）已確認有專用戰鬥消費端。
- 龍騎士雙手防禦已確認依雙手武器及敵人體型接入減傷。
- 四項容量型技能（僕從武裝－印記、暗影附魔、舞動之刃、衝擊坑）仍明確標記效果待實作；不以假效果冒充完成。
- 生化學者四項召喚名稱被動目前是常駐能力加成，不會建立獨立召喚物；元素支配者五種元素召喚則保留實際召喚流程。

## 特性與傷害公式驗證
- POW 每 3 點 +1 P.ATK；SPL 每 3 點 +1 S.MATK；CON 每 5 點同時 +1 P.ATK／S.MATK。
- CRT 衍生 H.PLUS 與 C.RATE；裝備 C.RATE 及 P.ATK／S.MATK 固定值只計算一次。
- 重複 recomputeDerived 不會重複累加裝備加成。
- 近距離／遠距離物理加成與魔法傷害路徑分離；物理技能傷害鏈傳遞技能 metadata。
