# v2.5.484 深淵追跡者技能修正報告

## 依據
- 依使用者先前提供的技能影片 `1000013582.mp4` 截圖（技能圖鑑第 35、40、45、50、55、60、65、70 畫面）核對名稱、技能類型、最高等級、SP、冷卻、倍率與武器限制。
- 以 v2.5.483 完整專案為基底；本次沒有重置角色、LocalStorage 或寵物存檔。

## 已修正的問題
1. **厄運突擊（Unlucky Rush）**：影片明確標示「對場上全體敵人」的無屬性 ATK 700%～1300% 物理攻擊。原程式錯設為單體 `damage`；改為 `damage_aoe`，接入現有全體物理傷害結算。
2. **狂亂射擊（Frenzy Shot）**：影片只標示 ATK 700%～1650% 傷害，沒有標示固定兩段或特殊暴擊倍率。原程式錯設 `damage_multi` 並固定 2 段，會把標示倍率再乘 2；改為 `damage` 單次總倍率，保留弓專用、SP 30～57、冷卻 2 秒。
3. **追擊射擊（Chasing Shot）**：影片沒有標示弓專用，移除原本額外加上的 bow 限制；保留無屬性 ATK 700%～1300%、SP 40～56、冷卻 4 秒。
4. **技能名稱**：16 招中文名稱依影片修正，避免技能樹、圖鑑搜尋與裝備描述使用不同譯名。
5. **卡片相容**：保留 `v25_abyss_chaser_10`、`v25_abyss_chaser_11` ID；蘿拉卡片仍正確連結深淵之域與深淵之焰。

## TWRO 技能清單交叉比對
- TWRO 技能資料庫列出的深淵追跡者本職技能為 16 招，與影片的 16 招逐項對應，沒有漏掉官方職業技能。
- 名稱採影片資料庫用語；下列括號列出 TWRO 資料庫對應名稱，避免不同譯名被誤判為重複技能：
  - 短劍與弓熟練＝短劍&弓弩精熟
  - 擊退滑步＝突擊滑行
  - 追擊破＝追擊突斷
  - 深淵之刃＝深淵匕首
  - 厄運突擊＝不幸衝擊
  - 靈巧穿刺＝靈巧刺擊
  - 魔劍熟練＝魔劍精熟
  - 源自深淵＝萬丈深淵
  - 深淵之域＝深淵墳場
  - 深淵強擊＝終結深淵攻擊
  - 暗影卸除＝卸除影子
  - 追擊射擊＝追襲射擊
  - 連鎖爆射＝連鎖射擊
  - 狂亂射擊＝狂暴射擊
- 官方技能說明與影片自訂版有若干差異（例如短劍與弓熟練／魔劍熟練的被動效果、厄運突擊的目標範圍、技能倍率及 AP 機制）。本作按使用者指定，以影片倍率和影片標示的自訂效果為準；官方資料用來核對職業技能是否缺漏，不直接覆蓋影片平衡值。
- 追擊射擊：TWRO 資料庫標示弓專用；影片自訂圖鑑未標示弓專用。本版按影片資料保留不限制武器，並在此記錄差異，避免誤以為是官方設定。
- 影片明確把源自深淵、深淵之焰、暗影卸除標為「效果待實作，僅補技能容量」，因此這三招暫不套用官方 AP／召喚球／雙區域多段／影子裝備效果。

## 本作已接入效果
- 主動物理單體／全體、暗屬魔法單體／全體均使用既有戰鬥引擎傷害分支。
- 深淵殺手使用既有 `buff_atk` 增益流程，保留 10%～60% ATK、40～90 秒持續時間。
- 短劍與弓熟練使用既有 `atkFlat` 被動流程；裝備短劍或弓時生效。
- 魔劍熟練使用既有 `atkFlat` 被動流程，依影片每級 ATK +3。
- 追擊射擊不再錯誤阻擋短劍以外武器；連鎖爆射、狂亂射擊仍保留影片明示的弓限制。
