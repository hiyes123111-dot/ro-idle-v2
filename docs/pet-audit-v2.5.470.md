# v2.5.470 寵物技能相容與恢復管線校正

## 本版範圍
- 基底：v2.5.469。
- 只處理寵物技能與自動戰鬥相容性、治癒量／HP／SP 恢復效果、特殊能力實裝狀態標記。
- 依使用者要求，變動詠唱縮短與技能後延遲縮短（原待辦第 1、2 項）完全不處理。
- 野外自動捕捉維持暫緩；不重置玩家 LocalStorage 或角色存檔。

## 修正項目

### Tamadora 自動戰鬥技能冷卻
- 普攻命中 1% 自動治癒觸發，改與自動治癒及手動治癒共用 `manualSkillReadyAt` 4 秒冷卻。
- 修正舊觸發器繞過自動／手動治癒共用冷卻的情況。
- 沿用既有 `castSkill('heal', {free:true, forceLv:1})` 技能結算；不另造治癒公式。

### 銀月魔女觸發條件
- 恢復官方描述要求的「近距離物理攻擊」條件。
- 僅近戰普通物理攻擊可觸發。
- 遠距離普通攻擊與物理技能不觸發。
- 其他寵物的受擊技能規則不變。

### 白幽靈隱匿技能
- 寵物面板新增「手動施放隱匿 Lv1」。
- 使用現有 `castSkill` 技能流程及技能自身冷卻。
- 不加入自動戰鬥輪替，避免掛機自動隱匿造成攻擊中斷。
- 稽核摘要改標示已實裝，不再列為待接入技能。

### 治癒量與自然恢復
- 已解析的寵物 `healPct` 經 `effectiveGearBonuses()` 進入既有 `healBonusPct`／`healOutputMult()` 治癒倍率。
- `hpRegenPct`／`spRegenPct` 經既有 `cardHpRegenPct`／`cardSpRegenPct` 進入自然恢復計算。
- 寵物月夜貓的 HP／SP 持續恢復沿用 `applyItemRecoveryTick()`，不重複寫一套恢復公式。
- 面板摘要會將治癒量、HP 自然恢復、SP 自然恢復標示為已接入計算。
- 未有可靠機率的 HP／SP 吸收效果不自行補造觸發率，維持待核對。

## 狀態標記
- 白幽靈隱匿：已實裝。

- 指定地圖增傷、移動速度、活動限定效果及外文未核對資料：維持待處理。
