# v2.5.433 大量怪物戰鬥效能優化（第二階段）

## 本版範圍
本版先優化怪物異常狀態的重複查詢，不更動戰鬥公式、攻擊間隔、技能觸發機率、傷害浮動、怪物行動頻率或掉落。

## 修改內容
- `ailList(mon)` 使用 `WeakMap` 快取怪物目前有效的異常狀態清單。
- 快取有效期限取該怪物目前有效異常狀態中最早的到期時間；到期後自動重建。
- `applyAilment()`、`applyStun()` 新增／延長異常狀態後立即失效。
- `ailBreakOnDamage()`、`wakeIfFrozen()` 移除異常狀態後立即失效。
- `WeakMap` 不會阻止怪物物件被垃圾回收，沒有把快取資料寫入玩家存檔。

## 為何先做這項
怪物傷害／命中／迴避結算會多次查詢同一怪物的異常狀態。原本每次都重新取時間、列舉狀態鍵並過濾；快取後在狀態未變且尚未到期時直接重用有效清單。

## 保留的遊戲行為
- 不改 `MON_AILMENTS` 狀態定義與免疫規則。
- 不改異常狀態持續時間、BOSS 時長減半規則。
- 不改中毒／出血 DOT 的跳傷頻率。
- 不改玩家與隊友的傷害、命中、迴避、攻速及技能施放。
- 不改怪物攻擊間隔、AI、生成數量、掉落機率。
- 不改存檔格式與玩家資料。
