# v2.5.473 寵物系統完善與整合稽核

## 基底與範圍
- 基底：v2.5.472。
- 本版完成自動餵食離線補算修正、寵物飾品圖鑑搜尋／相容性資料校正、寵物蛋索引補漏與寵物戰鬥／存檔回歸驗證。
- 不新增寵物能力數值、不改變已核實技能觸發率、不重置玩家 LocalStorage、角色存檔或個體培養紀錄。

## 1. 自動餵食與離線照顧
- 原照顧計時以分鐘計算，卻使用 `8 * 3600` 作為離線分鐘上限，實際上相當於 20 天；修正為 `8 * 60`，每次最多補算 8 小時。
- 離線補算逐分鐘處理飢餓度與親密度：先消耗飢餓度，飢餓度歸零後才降低親密度。
- 自動餵食不再等整段離線補算結束才嘗試一次；每次飢餓度降至 50 即嘗試餵食，成功後繼續等待下一個門檻。
- 飼料或鋅幣不足時，本次補算只嘗試一次，避免空轉；既有保留鋅幣規則不變。
- 仍保留每次最多 8 小時限制，超過部分由後續遊戲 tick 繼續補算。
- 若飢餓度與親密度都到安全下限，沿用原有安全收回寵物蛋機制，不讓寵物永久消失。

## 2. 寵物飾品與圖鑑
- 專案 ITEMS 中可辨識 42 件寵物裝備／可愛寵物裝備。
- 修正寵物蛋名稱後綴：支援「寵物蛋」、「魔物蛋」、「的蛋」及一般「蛋」；支援「混沌的」前綴正規化。
- 修正飾品裝載欄位解析，避免把「重量」等後續道具欄位誤併入適用寵物名稱。
- 42 件飾品的適用對象均能對應到圖鑑寵物資料。
- 寵物圖鑑可搜尋相容飾品名稱、ID 與道具說明，並顯示可用飾品清單。
- 目前這 42 件飾品的 ITEMS 說明只列外觀與裝載對象，沒有可核實的 ATK／MATK／DEF 等角色戰鬥數值；因此維持外觀裝備，不虛構戰鬥加成。
- 裝備仍隨個體 UID 保存；卸下放回背包；進化時自動卸下並返還飾品。

## 3. 寵物圖鑑資料補漏
- 補入銀月魔女蛋 `loli_ruri_egg`。其名稱／描述有孵蛋器資訊，但未含「寵物」關鍵字，先前索引規則漏掉。
- 寵物蛋索引由 132 增至 133 種；新增蛋使用既有通用飼料回退規則，不硬指定錯誤專用飼料。
- 銀月魔女低親密度圖鑑改顯示「達有點親密後開放」；有點親密及非常親密顯示已接入的受物理傷害治癒術觸發，避免錯誤列為待實裝。
- 六組既有進化配方維持原樣，搜尋仍支援進化前後名稱及材料。
