# v2.5.451 卡片圖鑑圖片與資料完整性修正

## 基底與範圍
- 基底：使用者目前提供的 v2.5.450 完整遊戲。
- 本輪只修正卡片圖鑑圖片顯示路徑與失敗備援，不更動卡片數值、觸發機率、傷害公式、掉落率或玩家存檔。

## 找到的問題
- 卡片格子雖然已有 `cardArtSrc()`，但 `codexItemCell()` 仍使用一般道具的 `itemImgSrc()`，會以道具圖片路徑載入卡片圖，造成卡片縮圖錯誤或破圖。
- 卡片詳情標題圖示也使用 `itemImgSrc()`，同樣會請求錯誤圖片路徑。
- 怪物詳情的掉落卡片列使用一般道具圖片路徑。
- 卡片大圖載入失敗時原本直接隱藏圖片區塊，沒有保留可辨識的卡片佔位圖。

## 修正內容
- 卡片圖鑑格、詳情標題、怪物掉落卡片列統一使用 `cardArtSrc()`。
- 非卡片道具仍使用 `itemImgSrc()`，不影響一般道具圖片。
- 卡片圖片載入失敗時改顯示卡片專用佔位圖，不再直接隱藏整個圖片區。
- 保留 `CARD_ART_FALLBACKS` 的既有生成 SVG；不以替代圖冒充官方卡面。

## 既有資料盤點
- 卡片資料：875 張。
- CARDS／ITEMS 對應：875／875。
- images/cards/generated 目錄共有 196 個 SVG；其中 127 個由卡片 fallback 表直接引用，逐一確認引用檔案存在。
- 發現同名資料候選 18 組、相同官方圖片 ID 候選 2 組；本輪不合併、不刪除，避免誤改玩家已持有卡片 ID。後續須逐組核對官方道具 ID、卡片效果與掉落來源，再決定 canonical ID 與舊存檔相容方式。

## 驗證
- `tools/v2_5_451_card_catalog_art_regression.js`：5 項檢查。
- 檢查所有卡片均有 ITEMS 對應。
- 檢查全部註冊的生成式卡片圖片檔案存在。
- 檢查圖鑑格、詳情標題、怪物掉落列均使用卡片圖片來源。
- 檢查圖片失敗時有卡片佔位圖備援。

## 保護
- 不修改玩家存檔格式或內容。
- 不清除 LocalStorage。
- 不修改怪物、卡片、道具取得機率。
- 本輪未把未核實的卡片效果標成已實裝。
