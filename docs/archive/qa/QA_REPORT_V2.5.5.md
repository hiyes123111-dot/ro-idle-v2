# V2.5.5 QA 報告

## 本版實際修正
- 修正技能增傷欄位與技能 ID 前綴不一致的情況。舊裝備常用 `skillDmg_arrowstorm`，技能實際 ID 為 `ra_arrowstorm`；現在先查完整 ID，無值時回退短 ID，讓既有武器／卡片增傷可以進入實際傷害乘區。
- 普攻觸發型技能的傷害加成也改用相同的技能增傷解析函式，避免主動技能與被動觸發技能計算方式不同。
- `damage_aoe`、`magic_aoe` 納入施放前目標檢查，沒有怪物時不再扣 SP 或啟動冷卻。
- 保留技能描述依實際 `mult` 陣列產生的倍率範圍。
- 資料夾與版本檔統一為 2.5.5。

## 測試
- `node tools/v2_regression.js`：ALL PASSED，0 failures。
- 31 組裝備套裝回歸測試通過。
- 四轉技能倍率描述與實際 `mult` 陣列一致性通過。
- 三轉技能倍率描述存在性測試通過。
- +2 精煉合金光以太神弓的 `skillDmg_arrowstorm` 可正確套用到 `ra_arrowstorm`，測試值 +5% 通過。
- 無目標時範圍技能施放前守門檢查通過。
- 全部 JS 檔案語法檢查通過。
- ZIP 完整性檢查通過。

## 已知尚未完成（本版不宣稱已修復）
