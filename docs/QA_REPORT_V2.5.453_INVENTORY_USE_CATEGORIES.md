# v2.5.453 背包用途分類 QA

## 變更
- 新增「附魔使用」與「寵物使用」兩個背包用途分類。
- 分類為檢視索引，不修改 ITEMS/CARDS 原始道具資料、存檔格式或持有數量。
- 附魔分類只收錄 material/consumable 類型，依道具名稱與 ID 前綴識別附魔石、附魔票、精髓、改造模組、冰花／雪花魔石及相關材料。
- 寵物分類依寵物蛋、寵物飼料、孵蛋器、捕捉／馴服字樣及寵物道具 ID 識別。
