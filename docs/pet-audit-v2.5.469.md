# v2.5.469 寵物被動戰鬥管線校正

## 本版範圍
- 以 v2.5.468 為基底，修正寵物被動效果的種族雙增傷重複解析，並補強戰鬥管線回歸測試。
- 校正寵物面板對攻擊後延遲、變動詠唱及技能後延遲的顯示語意。
- 不改動寵物官方效果數值、進化配方、飾品、野外捕捉或玩家存檔。

## 修正項目
### 種族物理／魔法雙增傷重複計算
- 原解析器先將「對某種族的物理、魔法傷害+N%」同時加入物理與魔法增傷桶。
- 後續獨立的「魔法傷害+N%」解析又匹配同一段文字，導致魔法增傷重複加入。
- 現在先辨識雙增傷句並遮罩已處理的文字，再解析獨立物理或魔法句。
- 艾斯恩魔女：人型物理+3%、魔法+3%（修正前魔法錯誤成+6%）。
- 狂暴木乃伊：龍族物理+6%、魔法+6%，兩者各只套用一次。

## 面板顯示
- 「攻擊後延遲- N%」改以「攻擊間隔縮短 N%」顯示，與實際攻擊間隔公式一致。
- 變動詠唱縮短及技能後延遲縮短會清楚標示「未套用」，不再顯示成含糊的正負數。
- 其他寵物被動數值仍沿用既有戰鬥計算管線。

## 戰鬥管線測試
- `tests/test_pet469_battle_pipeline.js`：12 項專項測試通過。
- 測試使用 engine.js 內實際 `canonicalBonusKey` 與 `getCardBonus` 函式，驗證寵物效果進入裝備／卡片共用戰鬥加成讀取器。
- 驗證 MDEF、種族承傷減免、物理／魔法種族增傷、攻擊後延遲、元素魔法傷害。
- 驗證直接素質（HIT）不會同時進入 gear bonus 桶而重複計算。
- 驗證親密度變化即時讀取新階級，收回寵物後加成歸零。
- index.html 查詢字串、Service Worker runtime cache、VERSION.txt 統一為 2.5.469。

## 保留項目
- 變動詠唱與技能後延遲仍標示未套用；本作目前沒有完整施法時間／技能後延遲模型，本版不捏造計算方式。
- 野外自動捕捉維持暫緩。
- 不清除玩家 LocalStorage、不重置角色存檔。
- 新程式放在 `js/`、測試放在 `tests/`、稽核文件放在 `docs/`。
