# 寶箱／卡冊獲得通知 UI v2.5.104

## 功能
- 通知面板位於戰鬥場景左下方，覆蓋原本空白對話泡泡區域，不取代玩家／怪物顯示。
- 寶箱、神秘箱、紫箱、卡冊及部位卡冊等 `boxOpen` 容器，單次開啟與批次開啟都會記錄。
- 每筆包含 item id、數量、來源、時間；最近 30 筆存在玩家存檔狀態中。
- 面板顯示最近 3 筆，較新項目在上方；相同道具、相同來源在短時間內會合併數量。
- 支援收合／展開、完整紀錄清單，以及點擊項目查看道具說明。

## 刻意排除
- 一般怪物掉落、任務獎勵、商店購買、交易與倉庫存取不會出現在此清單，避免把非寶箱／卡冊獎勵混入。
