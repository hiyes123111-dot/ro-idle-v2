## 四、其他值得分類但不應直接當成閒置的素材

- **寵物認養物品與寵物蛋**：描述中有寵物用途，應由寵物認養／孵化流程判定。
- **狀態治療道具**：綠色藥水、聖水、萬能藥等，雖然 `type` 是 material，仍可能由通用使用系統處理。
- **技能捲軸、召喚道具、活動箱、任務鑰匙**：需區分通用道具使用、活動限定與任務流程。
- **卡片、附魔石、服裝潛能石等被標為 material 的資料**：不能依 type 單獨判斷用途。
- **收集商人／收藏家素材**：描述若明確表示可出售，暫列收藏出售；除非後續設計新系統，否則不建議全部轉成製作材料。

## 五、建議的後續設計順序

1. **職業之魂**：六種素材名稱與職業對應明確，適合規劃成職業專屬兌換／強化線；先確認來源與掉落量。
2. **三種王者靈魂碎片**：適合規劃成區域首領系列兌換素材，避免與六職業之魂混用。
3. **福金之魂、霧尼之魂**：描述已寫明可抑制耶夢加得力量，應先核對相關地圖／首領機制，可能原本就是任務或進場素材。
4. **龍鱗系列**：普通龍鱗、紅鱗碎片、脫落的紅色龍鱗、堅硬的龍鱗需先依來源與稀有度分級，避免與 V2 熾焰龍鱗重複。
5. **瓦爾基里力量碎片**：描述只寫可賣給收藏家，可作為瓦爾基里主題的次級素材，但需與已存在的「瓦爾基里的象徵」區分定位。

## 六、檔案說明與限制

- `materials-usage-inventory-v2.5.97.csv`：完整逐筆清單，包含 ID、名稱、描述、重量、售價、程式引用數、引用檔案與初步狀態。
- 程式引用掃描以 JS 識別字 token 精確比對 ID；不代表完整追蹤所有執行時資料流。
- 尚未逐一人工追查每個素材的怪物掉落表、活動任務入口、通用使用流程，因此不將無引用項目直接判定為刪除對象。
- 本階段沒有新增任何道具用途或配方，也沒有調整任何道具數值。
